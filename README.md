# collab_space

Kurzüberblick

Dieses Repository enthält gesammelte Materialien für Vorlesungen und Referate.

Hauptordner (Auszug):

- `Formelsammlungen/` — Sammlung von Formelsammlungen, nach Fach geordnet (z. B. `Mathe_1`, `Physik`, `TonTechnik`, `VideoTechnik`).
- `Referat_Geschichte_der_Fotografie/` — Präsentation, Notizen und Bilder für das Referat.
- `Style/` — Gemeinsame LaTeX-Stil- und Header-Dateien.

Ziel

Am Ende sollen in den jeweiligen Ordnern der `Formelsammlungen/` nur die fertigen Formelsammlungen als PDF-Dateien liegen (keine `.tex`, `.aux`, `Makefile`-Dateien oder Quellartefakte).

Hinweise

- Quelldateien (LaTeX, Skripte) können lokal oder in separaten Branches verbleiben; die Hauptstruktur soll nur die finalen PDFs zeigen.
- Wenn gewünscht, füge ich gern eine `.gitignore` und eine kurze Anleitung zum Erstellen der PDFs hinzu.
